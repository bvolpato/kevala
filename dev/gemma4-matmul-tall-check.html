Gemma 4 Q8/F32 BM104 matmul probe

Compares the registered Q8/F32 R4 row56 kernel with a DEV-derived physical BM104 kernel for T=97. The candidate keeps the BM64 split rule, Q8 decode and scale operations, shared weight swizzle, K32 dot order, and the same split reducer.

Checks every Y value and PART plane bit-for-bit, including non-finite values, signed zeros, NaN input padding, and four-float tails, before and after paired GPU timestamps. Temporary GPU buffers and host staging stay within 64 MiB; immutable Q8 weights and scales are reported separately. No runtime kernel is changed.

Run ?shape=gate&T=97 for the primary 6144x1536 case. Add &all=1 to check down and wide shapes too. Timing requires WebGPU timestamp-query.
