Model runtime smoke check

Checks typed answers, probabilities, repeated requests, and batching on one WebGPU model. This checks the runtime contract, not answer accuracy.

Set model=laya, or model=kev-0.8b&pack=/tmp/kev-0.8b-bf16.kevala. A pack URL alone also works. Add auto=1 to start automatically, timing=1 for warmed timing samples, or features=timestamp-query,shader-f16 to restrict optional GPU features.

The default batch bound is max(0.0005, half the response rounding unit): an API compatibility check, not raw numerical equivalence. An explicit batchTolerance from 0 through 0.01 changes only that bound. Retain the baseline revision and before/after raw-vector artifacts when comparing code revisions; this harness records vectors but does not perform that comparison. Repeat, normalization, and scalar guards remain separate.

Inputs default to paragraphCounts=1,3,6. For bounded-memory coverage, choose three unique ascending counts from 1 through 6, such as paragraphCounts=1,2,3. The selected counts are recorded with the result.
