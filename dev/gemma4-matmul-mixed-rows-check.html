F32 BM56 plus BM48 suffix tiles

Dev-only T97 comparison of two registered BM56 row tiles against one unchanged BM56 tile followed by one registered R3/BM48 tile whose row origin is shifted to56. Both retain the original batch split partition and use the same R4 reducer once. The candidate computes104 padded rows instead of112.

Defaults to the 6144×1536 gate. Use ?shape=down, ?shape=q2048, ?all=1 or ?guards=1. Every output and split partial is checked by raw bits before and after timing across all six mode/bias combinations. Input padding contains NaNs, and output/partial tails use sentinels. Controlled host/GPU temporary allocations stay below64MiB; immutable weights are reported separately.
