Gemma Q8/F32 next-block prefetch probe

DEV-only T=97 suffix matmul comparison. The candidate reads the next K32 block into private registers while the current shared tile is consumed, then stages it with the production Q8 decode and swizzle. It keeps the registered Q8/F32 R4 row56 arithmetic and reducer. The page checks full Y and PART planes, tails, all three modes, and bias off/on before and after three alternating timestamp pairs of four repetitions. It runs only these GPU kernels and synthetic weights. Temporary GPU buffers, mapped host copies, upload staging, and queued uploads stay within 64 MiB beyond immutable Q8 weights.

Opening the page starts the probe. The default run checks gate 6144×1536, gate 12288×1536, and down 1536×6144. Use ?shape=gate&T=97 for the primary case, or ?all=1 for the Q, K/V, and O projections too. This measures matmul milliseconds only; it does not run the camera or model.
