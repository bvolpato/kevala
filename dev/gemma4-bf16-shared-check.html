Gemma 4 vision BF16 shared-tile probe

Compares the registered T=144 BF16/F32-tile matmul against a DEV-only source-derived variant that stores raw BF16 words in the shared weight tile, then decodes to the same F32 values at the original dot reads. It changes only the shared tile type, its writer/reader swizzle, and the decode point. The reducer and virtual split policy stay registered.

The primary pass checks every Y value and PART plane bit-for-bit and finite for mode 0 with bias disabled, before and after alternating GPU timestamps. Add full=1 to add tiny-subnormal and large-finite BF16 fixtures, all modes, and bias on/off. The 64 MiB cap includes temporary GPU buffers, bounded host staging/readback, queued upload allowance, and shader source scratch. The shared BF16 fixture weight buffer is reported separately and reused by both paths. No model pack is loaded.

Default selects the three core vision matrices: gate/up 3072x768, down 768x3072, and attention 768x768. Use ?shape=projection for 1536x768, ?all=1 for all four actual matrices, or ?shape=all for the three core shapes. Add ragged=1 to include N=770. Requires WebGPU timestamp-query.
