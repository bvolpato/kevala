Gemma 4 image preprocessing GPU exactness check

This DEV probe compares the Q22 GPU resize and normalization path bit-for-bit with the CPU image processor and vision image plan. It loads no model or weights. The seeded image patterns prove preprocessing exactness and cost only; they say nothing about image quality or model accuracy.

Run all four fixtures at budgets 16, 40, and 70 with ?autorun=1. Add &edges=1 for bounded tiny and edge fixtures, &case=camera-a or &budget=40 to narrow the run. GPU timestamps are reported only when the adapter exposes timestamp-query; otherwise the probe runs exactness checks without GPU timing.
