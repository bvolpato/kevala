Gemma 4 Q8/F32 T97 packed-weight layout probe

Compares the registered R4/BM56 row-major Q8 matmul with a DEV-only variant whose Q8 bytes use [Ntile64,Kblock32,Nwithin64,packed32B] order. The candidate changes only the W vector address. It keeps the original scale addresses, Q8 decode, shared-memory layout, barriers, K32 dot order, split rule, and reducer.

The page constructs the permuted weight bytes through bounded 1 MiB CPU staging, uploads an equal-size packed W buffer, and reports CPU packing and upload time separately from steady-state GPU timestamps. It verifies the full address permutation and tile-boundary samples, then checks every Y value and PART plane bit-for-bit across all mode/bias combinations before and after paired timing. Checks include finite active values, NaN-padded input rows, signed zeros, and four-float tails. Temporary GPU buffers and host staging stay under 64 MiB; the immutable original Q8 W and scales are excluded, while packed candidate W is counted.

Run ?shape=gate&T=97 for the primary 6144x1536 case. Use ?shape=down&T=97 for 1536x6144, or ?all=1&T=97 for both shapes. Requires WebGPU timestamp-query.
