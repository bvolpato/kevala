Gemma 4 Q8/F16 BM104 matmul probe

Compares the registered Q8/F16 R4 BM64 kernel with the registered physical BM104 kernel at T=97. Before compiling, it asserts that the registered BM104 source and its DEV-derived reference have identical bytes and SHA-256 hashes. The candidate retains the Q8 decode and scale, F16 shared-tile casts and swizzle, K32 staging and barriers, per-output ascending Kq dot/add order, virtual BM64 split policy, and the same reducer.

Checks every Y value and PART plane bit-for-bit, including non-finite values, signed zeros, NaN input padding, and four-float tails, before and after paired GPU timestamps. Temporary GPU buffers and host staging stay within 64 MiB; immutable Q8 weights and scales are reported separately. Requires shader-f16; no F32 fallback is provided. No runtime kernel is changed.

Run ?shape=down&T=97 for the primary 1536x6144 case, or use the default to include the Q projection guard at 2048x1536. Use ?shape=q2048&T=97 to time only that case. Timing requires WebGPU timestamp-query and shader-f16.
