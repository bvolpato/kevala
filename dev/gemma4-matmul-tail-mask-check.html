Gemma 4 Q8/F32 T97 dead-row accumulation probe

Compares the registered R4/BM56 row56 matmul against a DEV-only variant that skips only dead acc6 and acc5 dot steps in the T=97 tail tile. Both retain the same logical BM64 split rule, BN64 grid, Q8 decode and scale, shared-memory loads, barriers, and K32 dot order for every live row.

Checks all Y values and PART planes bit-for-bit, including finite outputs, NaN-padded input rows, signed zeros, modes, bias, and four-float tails before and after paired GPU timestamps. Temporary GPU buffers and host staging are capped at 64 MiB; immutable Q8 weights and scales are reported separately. No runtime kernel is changed.

Run ?shape=gate&T=97 for 6144x1536. Use ?shape=down&T=97 for 1536x6144, or ?all=1&T=97 for all three shapes. Requires WebGPU timestamp-query.
