Clef CPU finish benchmark

CPU finish only. The same captured backbone output is replayed through two coordinators. This does not measure an end-to-end speedup.

Required query parameter: packSha256 (verified offline full-pack digest). Optional: runtime (default ../js/src/index.js), baseline (default ../tmp/baseline-runtime/), pack, flavor, tile=0|1. Pass frozen runtime and baseline URLs explicitly for comparisons. Run through the serialized GPU queue.
