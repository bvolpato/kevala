# Kevala 0.2.2

Kevala 0.2.2 packages the WebGPU, CPU kernel, memory, and profiling changes that landed after 0.2.1.

## Changes

- Clef-flash stages seven F32 head projections across two WebGPU waves by default (`clefHead: "auto"`, with `"cpu"` retained as a control). Normal load warmup validates every GPU output bit against the CPU reference before enabling the staged path. CPU head execution also skips unused routing projections and computes shared self-attention Q/K/V projections once.
- Kev and SemIf skip duplicate token-embedding work on cached state prefixes and omit retained carry cache slots when `stateCache: false` is set. Qwen3.5 prunes final-block MLP work to selected scorer rows, and Gemma 4 adds a calibrated 32-lane attention path for unbatched 257 to 640 token requests.
- WebGPU submission policy (`submit: "await" | "split" | "none"`) stays isolated on each engine instead of sharing a page-global setting.
- Native CPU builds vectorize Q8 embedding and row decoding, add runtime AVX2 `2x4` and `4x4` linear projection packing, and add a CPUID-gated four-row AVX-512 path for the measured Zen 5 processor revision.
- Resident model and kernel profilers record wall and GPU lanes, Clef head routes, module-load failures, and per-request stage timing summaries. The speed page links the stage and host-control breakdowns.

## Validation and limits

Staged Clef GPU head projections reduced median paired warm request latency by 27% to 37% across three Q8 text lengths on Chromium 156 and an RTX 5070 Ti, with exact finite-bit projection parity ([Clef GPU head report](../clef-head-performance.md)). Earlier catalog sweeps recorded 6.1% to 9.1% lower Clef whole-request wall time and 24.4% to 26.3% lower CPU-finish replay time, while sequential wall medians across other catalog models were mixed ([model optimization report](../model-optimization-performance.md)).

Setting `stateCache: false` reduced Kev-0.8B Q8 explicit carry allocation on the first stateful request from 367,132,672 bytes to 25,968,640 bytes, a 325.36 MiB reduction, without changing whole-run peak explicit buffer capacity after later cache growth ([GPU cache memory report](../gpu-cache-memory.md)). Native CLI CPU timings on a Ryzen 9 9950X3D recorded 2.79% to 9.03% implied paired time reductions for the Zen 5 AVX-512 path across four Laya and Kev-0.8B Q8 requests, although every experimental quartet range crossed 1.0 and the independent short Kev-0.8B median was 1.13% slower ([native AVX-512 report](../native-avx512-performance.md)).

Rejected GPU epilogue fusions, resident FP32 weight caching, K64 tiling, and cold Gemma calibration-budget changes remain disabled by default ([host follow-up report](../host-followup-experiments.md), [FP32 reference report](../performance-reference.md)). Kev-9B BF16 profiling covers short and medium shapes only ([Kev-9B BF16 profile](../kev9-bf16-profile.md)). Larger packs remain unpublished on Hugging Face, other GPUs and browsers need separate measurements, and the 60 FPS camera target remains unmet.

## Package scope

The npm package contains the browser and Node runtime and three WebAssembly flavors. Model weights remain separate packs. This release does not include a native macOS CLI binary.
