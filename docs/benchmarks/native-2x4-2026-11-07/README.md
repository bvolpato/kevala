# Native 2×4 evidence archive

This archive accompanies the [native 2×4 performance report](../../native-2x4-performance.md). The original production-validation receipt is `production-validation-v2/receipt.json` (SHA-256 `113dae26ef03fa193f573e25af944fbad0e26429d4f75f61c7474ad3043b9b5f`), and its inventory is `production-validation-inventory-v2.json` (SHA-256 `ddb3d3d8fe8ebd4167d6fc61329641a400cf8f2c5bb944af42772df7528f1137`). Three corrective numerical guards passed with explicit artifact paths, the environment override unset, and before/after hashes. Their receipt is `numerical-artifact-binding-v2-r1/receipt.json` (SHA-256 `3ad9b9a350cda8c88109e3404d94aa2f2ab6fbfdd2e0b69918245af5b863e53a`); amendment `numerical-binding-amendment-v2-r1.json` has SHA-256 `ce296ce68b0b50bff616142c1130a8d17fedbac01204e2c9e494dbd497611423`, and the binding inventory has SHA-256 `3732451842f13e3e64498f23cf6e268fe0cfd20e4e8561ebcb45239fe8d9b73d`. The independent artifact-binding audit passed. The manifest binds the original and corrective validation records, source inventories, raw observations, and derived statistics.

The archive uses deterministic gzip JSON envelopes, following the existing native-linear archive format. Its flat `raw/` directory separates frozen-v1 sources and failure records, frozen-v2 sources and gates, the v2 micro screen, paired CLI evidence, and validation evidence. Each envelope entry records its original relative path, byte count, SHA-256, and exact source bytes. `manifest.json` binds each compressed envelope, its decoded bytes, each contained file, the derived statistics, and the corrective artifact-binding receipt.

The archive preserves the failed frozen-v1 callback attempt and its classification, the accepted frozen-v2 sources and patch, v1/v2 gate records, the v2 micro screen and host telemetry, the paired CLI plan, all 84 model observations and responses, the non-model `execve` preflight transcript, exact source receipts, and complete relevant assembly-function extracts. It also includes a derived-statistics file for conventional arm medians and paired ratios. The original summaries and raw records remain unchanged.

The two broad micro disassemblies are omitted with exact byte and hash descriptors; scoped complete function extracts remain in the bundle. The archive excludes model weights, measured activation and hidden-state buffers, compiled binaries, build output, and credentials. It includes tracked public source fixtures needed to reproduce builds and checks, including fixtures with toy tensor/value data and deterministic synthetic patches. Those fixtures are source test inputs, not benchmark weights or measured activation buffers. Excluded source inputs are listed by original path, byte count, and hash. Source files are stored in compact flat envelopes; original source paths may remain as JSON metadata. The physical tree contains no directories named `tmp`, `crates`, `target`, `packs`, or `node_modules`.

The manifest binds the original validation records, the corrective artifact-binding evidence, the independent review, and the source and experiment identities. The original receipt's command outcomes remain recorded; the corrective evidence closes its artifact-binding gap. Existing v2 gate, micro, and paired receipts retain their own experiment scope and are not replaced by the production-validation receipt.

Archive and verify while holding the canonical profile lock in the current process. From the repository root, the launcher is:

```sh
flock --exclusive --nonblock --conflict-exit-code 75 --no-fork /home/bruno/.cache/kevala/gpu-profile.lock node docs/benchmarks/native-2x4-2026-11-07/archive-publication.mjs --archive --allow-io --evidence /home/bruno/githubworkspace/kevala/tmp/sota-20261106-kdDTGn/native-2x4
flock --exclusive --nonblock --conflict-exit-code 75 --no-fork /home/bruno/.cache/kevala/gpu-profile.lock node docs/benchmarks/native-2x4-2026-11-07/archive-publication.mjs --verify --allow-io
```

The script checks `/proc/locks` for the current process and the canonical lock inode before archive reads and again after writing or verification. `--plan --evidence /absolute/path` reads the fixed inventories and file metadata only; it does not read or copy experiment payloads.
